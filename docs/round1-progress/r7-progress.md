## Findings that shape the design (read before coding)
1. **Built CSS minifies literals to hex8.** `rgb(20 35 28 / .14)` ships as `#14231c24`. In `.next/static/chunks/*.css` the colour literals are: core hexes `#14231c #1c2e25 #f1ece0 #e3dccb #c8b9a0 #566059 #a9895c`, canopy-alpha `#14231c24/4d/2e` (rules on light, texture vignette) and in Hero.css `#14231cb8/94/6b/24/00` (scrim), bone-alpha `#f1ece0a3/66/29/52/6b` (dark aliases, preloader descriptor) and `#f1ece0b8/80` (hero tagline/eyebrow/cue). `#fff/#000` appear only in the print block. The HTML's only hexes are the theme-color meta.
2. **`--c-canopy` has two roles**: it is the dark ground (body bg, `.ground`, route curtain, preloader veil, header fallback, GroundManager dark bg) *and* the ink (`--fg` on light, `[data-surface=light]`, RowGlow/team glow tints, PortraitPlaceholder gradient). A palette whose "dark" ground turns light needs a separate `ink`.
3. **GroundManager hardcodes the fg mapping**: dark gives fg `--c-bone`, light and mid give fg `--c-canopy`. It reads the tokens once at mount through readToken, so a CSS rewrite does reach it, but a palette where dark-ground text is not bone (or ink is not canopy) needs the tooling to fix `--ground-fg`. Plan: an init-script MutationObserver on `<html style>` that maps the `--ground` value to the palette's fg. Also report this as a finding: the real implementation would need a token such as `--ground-dark-fg`.
4. **Direct colour uses outside the aliases** that an override sheet must cover: Hero.css (`.hero__scrim` gradients, `.hero__lockup` and `.hero__content` colour bone, `.hero__tagline` and `.hero__eyebrow` bone/.72, `.hero__cue` bone/.5, `.hero__rule` brass), Statement.css `.statement__mark` and sections.css `.one__mark` (bone at .16), Header.css (fallbacks, `[data-menu-open]` colour bone), RouteCurtain.css (canopy/bone), sections.css preloader (`.preloader__veil` canopy, `.preloader__inner` bone, `.preloader__descriptor` bone/.42), `.texture__vignette` (canopy/.18), sections.css `.team__glow` and RowGlow.css (canopy tints), PortraitPlaceholder.css (canopy stop-colours), globals `.skip-link`, `::selection`.
5. **AmbientGradient** (WebGL, desktop ≥1024 with motion) reads `--c-canopy`, `--c-canopy-soft` and `--c-stone` at mount, so the CSS rewrite covers it.
6. **Accent as text**: `.field__error` (`t-small`, `var(--accent)`) on the enquiry sheet (`[data-surface=light]`, bone) and the assessment form (light ground). The current brass `#a9895c` on bone is about 2.9:1 and **fails AA today**. Report this as a finding. The gating decision is still open: gate accent-as-text on bone at 4.5 (which means a deep bronze of luminance ≤ ~0.14 that nearly vanishes on dark grounds), or report it as advisory. I leaned towards gating on bone only and making every non-Current palette pass. `.team__presence` and `.day__time` accent text are no longer rendered (grep found no tsx usage).

## Planned design (not yet written)
- `design/palettes/palettes.json`: `{ palettes: [{ id, name, character, core:{canopy,canopySoft,bone,sand,clay,stone,brass}, ink?, dark:{fg,muted,faint,ruleAlpha,ruleStrongAlpha}, hero:{scrim,fg,muted,faint}, grade:{shadow,highlight,contrast?,lift?} }] }`, with "Current" first holding today's values (ink=canopy, dark fg bone, muted bone/.64, faint bone/.40, hero scrim canopy, grade shadow #182a21 / highlight #e9e2d3).
- `scripts/palettes/`:
  - `palettes.mjs`: load, validate and resolve defaults.
  - `contrast.mjs`: WCAG math with alpha compositing; writes `design/palettes/CONTRAST.md`; exits non-zero if a non-Current palette fails a gated pair. Gated pairs: fg and muted on bone, sand, canopy, canopy-soft and the light surface; dark fg/muted on canopy, canopy-soft; hero fg over scrim composited on the grade's highlight (estimate, 3:1 for large text, 4.5 for the eyebrow); accent text on bone (decision pending, see finding 6). Advisory: faint, brass as non-text 3:1.
  - `grade.mjs`: regrade from the served `public/media/*.webp` by inverting the pipeline's duotone. Read SHADOW and HIGHLIGHT out of `scripts/prepare-assets.mjs` by regex; per-channel linear inverse, then `recomb` average to grey, optional contrast and lift, then the new duotone via `linear`. Write to `design/palettes/out/graded/<id>/<key>.webp`. This needs no network and tracks whatever R1 puts in public/media.
  - `inject.mjs`: (a) CSS response rewrite, core hex → palette, `#14231cXX` → ink+alpha, `#f1ece0XX` → dark.fg+alpha, 8-digit forms first, case-insensitive; (b) an override `<style>` appended at DOMContentLoaded with `html:root` / `html [data-ground='dark']` / `html [data-surface='light']` specificity plus the direct-use rules from finding 4; (c) the chrome `--ground-fg` observer.
  - `capture.mjs`: entry point. Runs the contrast check, regrades, launches Chromium against `PALETTE_BASE_URL` (default `http://localhost:3417`), intercepts CSS, images and video, and captures Home, About, a service (`/clinical-services/addiction-treatment`), a profile (`/team/caroline-adams`), `/self-assessment`, a questionnaire (`/self-assessment/alcohol`) and `/contact` at 1440×900 (DPR 1), plus Home at 390×844 (DPR 2). Output goes to `design/palettes/out/captures/<id>/<route>-<width>.png`. CLI: `--palettes current,limestone,sage` and `--routes home,...`. For non-Current palettes, add a stale-colour audit that walks computed colour, background and border colours plus SVG fill and stroke, and flags any Current core RGB still present.
  - Add `design/palettes/out/` to `.gitignore`. Optionally add an npm script `"palettes": "node scripts/palettes/capture.mjs"`.
- Palette directions (hex values not yet chosen; derive them with the contrast script): two families.
  - (A) *deep-lifted*: the dark ground becomes a mid-deep tone at luminance ~0.05–0.09 with bone text. Candidates: sea glass teal, cenote blue, jungle shade green, clay terracotta, sage.
  - (B) *light-inverted*: the dark ground becomes a mid-light warm tone with ink text, the hero gets a light scrim and ink lockup, and images are graded light. Candidates: limestone, linen, mist, shell, sand dune.
  - Suggested ten: Limestone, Sage, Sea Glass, Clay, Sand Dune, Mist, Cenote, Jungle Shade, Shell, Linen.
  - Constraint math, using bone luminance about 0.84: a dark ground with bone text needs luminance ≤ ~0.14 for 4.5:1, and muted text on it needs a higher alpha than .64 as the ground lightens.
